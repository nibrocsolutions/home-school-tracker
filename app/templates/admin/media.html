Media Library

Organize lesson files in subject folders, then attach one or more files from Edit Lesson Plan.

How to add files

  1. On the server (or Raspberry Pi), open the project folder that contains docker-compose.yml.
  2. Copy files into a subject subfolder under media/. Example for History audiobooks: 
    mkdir -p media/history
cp -R ~/Downloads/the-story-of-civilization-vol4-united-states-audiobook-\(1of3\)/* media/history/
    Or keep the whole folder under History: 
    mkdir -p media/history
cp -R ~/Downloads/the-story-of-civilization-vol4-united-states-audiobook-\(1of3\) media/history/
  3. Default folders are created automatically: history, math, language-arts, science, and other.
  4. In the teacher lesson plan editor, click Add media files on an activity, browse a folder, and select one or more files.
