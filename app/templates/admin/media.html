Media Library

Drop audio, PDFs, and other lesson files into the media folder, then attach them from Edit Lesson Plan.

How to add files

  1. On the server (or Raspberry Pi), open the project folder that contains docker-compose.yml.
  2. Copy folders or files into media/. Example for your Story of Civilization audiobook: 
    mkdir -p media
cp -R ~/Downloads/the-story-of-civilization-vol4-united-states-audiobook-\(1of3\) media/
  3. Docker already mounts ./media into the app. New files usually appear immediately.
  4. In the teacher lesson plan editor, click Choose media on an activity to attach a file.
